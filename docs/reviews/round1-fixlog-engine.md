- **Редактор:** Goldfish-агент (редактор спецификаций), 2026-10-24.
- **Файлы:** `openspec/changes/add-phonebook-db-v1/specs/{storage-engine,backup-restore,performance-capacity,build-constraints,observability}/spec.md`.
- **Источники:** решения D-034…D-106 (журнал оркестратора); ревью `round1-expert-storage-sre.md` (EX1), `round1-goldfish-critic.md` (GF2), `round1-goldfish-comprehension-readiness.md` (GF1), `round1-expert-security-api-ux.md` (EX2) — только замечания к этим пяти capability; таблица противоречий в `design.md`.

- D-055, D-064 (каталог служебных деревьев, корзина вне индексов, инвариант для активных) → STO-06 (+ сценарий «перенос в корзину»; сценарий с двумя телефонами уточнён «однословным именем» из-за D-051), STO-04.

- D-035, D-063 (откат только при одном валидном слоте, полям невалидного не доверять, метрика) → STO-17 (переписано, + сценарий «равные txid»), STO-18 (трассировка).
- D-048, D-078 (таймаут запроса 2 с, 30 с — для интерактивного снимка) → STO-24.

**Замечания ревью → требования:**
- EX1-01 → STO-03, STO-25; EX1-02 → STO-26, STO-33 (расширение файла записью нулей); EX1-03 → STO-10, STO-29 (≤ K страниц на коммит); EX1-04 → STO-34; EX1-05 → STO-19, STO-35 (перечитывание с диска и файл-маркер — `[ПРЕДЛОЖЕНИЕ АГЕНТА]`); EX1-06 → STO-15; EX1-07 → STO-27; EX1-08 → STO-31; EX1-09 → STO-32; EX1-10 → STO-29 (ленивое затирание — `[ПРЕДЛОЖЕНИЕ АГЕНТА]`), STO-23 (оговорка про FTL/COW-ФС); EX1-11 → STO-11, STO-13; EX1-13 → STO-38; EX1-15 → STO-01, STO-04, STO-17 (оба слота одинаковы, при равенстве — слот A, запись в слот, отличный от последнего коммита); EX1-16 → STO-36 (новое); EX1-17 → STO-37 (новое); EX1-21 → STO-17 (формулировка «возможна потеря ≤ 1 транзакции»); EX1-22 → STO-20 (один хэндл, сценарий для Windows), STO-23 (NFS/SMB); EX1-23 → STO-14 (сценарий через трейт `Storage` вместо `dtruss`).
- GF2-14, GF1-13, GF2-15 → STO-19, STO-33, STO-35; GF1-11, GF2-08 → STO-28; GF1-12 → STO-10; GF2-10, GF2-11 → STO-30; GF2-02 → STO-39; GF2-13 → STO-38; GF2-47 → STO-13.

**Не применено (с причиной):**
- EX1-04: чтение мета-страниц через `O_DIRECT` и пункт runbook о перезагрузке узла — D-088 выбрал переписывание мета-страницы; runbook не входит в спецификацию.
- EX1-01: CRC дочерней страницы в родителе (дерево Меркла) — рецензент дал это как опцию, D-085 её не выбрал.
- EX1-05 п. 4 (разные коды выхода для I/O и повреждения): по D-078 при повреждении процесс не завершается, поэтому второй код не нужен.
- EX1-20 (порядок выдачи по словам) и EX1-12 (компактная запись `idempotency_keys`) — не storage-engine (search, http-api) и без решения.
- STO-08, сценарий «линеаризуемость» (GF1 §2.2), — minor, очевидной правки нет.

**Вопросы:** D-088 говорит «both slots semantics», но описывает переписывание выбранного слота на месте. Внесено именно переписывание на месте; второй слот не трогается и получит следующий коммит (STO-04). Ссылка ADR-0018 (D-090) указана, хотя файла ADR-0018 ещё нет.
