# Раунд 1. Журнал правок: спецификации предметной области

Редактор: Goldfish (предметная область). Файлы: `specs/{contacts,phone-normalization,name-normalization,search,import-export}/spec.md` в change `add-phonebook-db-v1`. Источники: решения D-034…D-106, ревью раунда 1 (GF1, GF2, EX2 «Предметная область», EX1), таблица противоречий в `design.md`. ID требований не перенумерованы (D-040). Выбор редактора там, где решения нет, помечен в тексте `[ПРЕДЛОЖЕНИЕ АГЕНТА]`. Для согласованности со сделанными правками `http-api` (см. `round1-fixlog-interface.md`) использованы те же коды и пути: `invalid-page-token`, `page-token-expired`, `not-in-trash`, `GET /api/v1/trash`, модель задач API-32, поле `region` API-35.

Проверка после каждого файла: `npx --yes @fission-ai/openspec@1.15.0 validate add-phonebook-db-v1 --strict`.

1. SRCH-05: порядок внутри класса 1 — по наименьшему совпавшему ключу слова (D-074, EX1-20) вместо «by full name key» из D-062. Подтвердить.

4. `reason` = `contact-purged` для экспорта, прерванного purge (IMP-17), — подтвердить код.
5. Хранение и удаление загруженного файла импорта (GF1-19, GF2-20, EX2-15) — решения нет.
6. EX2-24 (bidi-символы в именах), EX2-40 (ударение U+0301, запятая и апостроф как разделители слов), EX2-31 (`доб` без точки), EX2-13 (позиции совпадения) — решений нет.
