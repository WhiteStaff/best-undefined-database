# Исходное задание (ДЗ)

Текст задания приведён дословно: его передал оркестратор (Elephant) по решению D-061. Ниже, отдельно от цитаты, перечислены дополнительные установки заказчика в пересказе.

## Текст ДЗ (дословно)

> ДЗ: Используя Open Spec, создайте спецификацию по следующим вводным:
>
> База Данных
>
> • Должна быть хорошей базой данных
>
> • Должна иметь Визуальный Пользовательский Интерфейс и программное API
>
> • Должна хранить Имена и Телефоны
>
> • Можно искать Имена по номеру Телефона
>
> • Можно искать Телефоны по Имени
>
> • Должна надежно хранить много записей
>
> • Написана с нуля на (подставьте ЯЗЫК ПРОГРАММИРОВАНИЯ)
>
> Принципы о которых мы говорили: Critical User Journey; Elephant + Goldfish; (architectural) Decision Record; LLM-expert review; Fact Grounding

## Принципы курса

| № | Принцип | Где применён |
|---|---|---|
| 1 | Critical User Journey | `docs/cuj.md` (CUJ-01…CUJ-10, D-028); трассировка CUJ → требования в `docs/traceability.md` |
| 2 | Elephant + Goldfish | оркестратор — Elephant, все исполнители и рецензенты — Goldfish (D-001, D-006, ADR 0001); журнал цикла — `docs/reviews/GOLDFISH.md` |
| 3 | (architectural) Decision Record | `docs/adr/` (MADR 4.0, D-005) и журнал решений заказчика `docs/orchestrator-decisions.md` |
| 4 | LLM-expert review | `docs/reviews/round1-expert-storage-sre.md`, `docs/reviews/round1-expert-security-api-ux.md` |
| 5 | Fact Grounding | ссылки на источники в `docs/research/01…03`; fact-check в экспертных ревью |

## Дополнительные установки заказчика (пересказ)

- Оркестратор выступает заказчиком и сам уточняет требования.
- Лучшие практики нужно искать в интернете.
- База полностью новая и пишется с нуля, без существующих решений.
- Выбор языка нужно обосновать (ADR 0002, D-020).
- Нужен подробный отчёт: что сделано, какие принципы применены, что дал каждый принцип, все принятые решения.
- Всю работу выполняют агенты; оркестратор хранит знания и принимает решения.
- Человек в решениях не участвует. Поэтому человеческий гейт цикла Elephant + Goldfish закрывает оркестратор как прокси заказчика (D-008).
